# Heli Empire - Game Design (draft v1)

## Core loop
1. Steal / collect helicopters on the map (steal-an-egg style map with levels).
2. Earn money from stolen helicopters.
3. Spend money on upgrades: **Speed**, **Health**, **Defense**.
4. Push further through the levels.

## Enemy
- Enemy helicopters try to stop the player from getting helicopters.
- Goal: the run to the end must take more than a minute.
- (Open: patrol/chase vs. flying obstacles - confirm with owner.)

## Upgrades
| Upgrade | Effect |
|---|---|
| Speed | Faster player movement |
| Health | More hits before reset |
| Defense | Flares, in different colours (tiers), that counter enemy attacks |

## Build order
1. Helicopter stealing + money
2. Upgrade shop (Speed / Health / Defense-flares)
3. Enemy helicopters
4. Level progression + UI (Figma)
